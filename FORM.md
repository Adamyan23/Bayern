# Заявки с сайта: письмо на почту + строка в Google Таблице

Всё бесплатно и без сервера. Нужен только аккаунт Google (`levon.adamyan23@gmail.com`).

Как это работает: человек нажимает «Отправить заявку» → сайт передаёт данные маленькому скрипту Google → скрипт пишет строку в вашу Таблицу и отправляет вам письмо.

Займёт минут 10. Делайте по шагам, ничего не пропуская.

---

## Шаг 1. Создать таблицу

1. Откройте https://sheets.new (вы должны быть в аккаунте `levon.adamyan23@gmail.com`).
2. Сверху слева, где написано «Новая таблица», впишите название: **BAYERN — заявки**.

Лист «Заявки» с заголовками появится сам после первой заявки.

## Шаг 2. Вставить скрипт

1. В этой же таблице в меню сверху нажмите **Расширения** → **Apps Script**. Откроется новая вкладка с редактором кода.
2. Там в окне кода будет несколько строк (`function myFunction() {}`). Выделите всё (**Ctrl + A**) и удалите (**Delete**).
3. Откройте файл [tools/form/Code.gs](tools/form/Code.gs) из нашего проекта, выделите весь текст, скопируйте (**Ctrl + C**) и вставьте в пустое окно редактора (**Ctrl + V**).
4. Нажмите значок дискеты (**Сохранить проект**) или **Ctrl + S**.

> Почта, на которую приходят письма, указана во второй строке скрипта: `const NOTIFY_EMAIL = 'levon.adamyan23@gmail.com';`. Захотите другую — поменяйте текст в кавычках. Несколько адресов пишите через запятую в тех же кавычках.

## Шаг 3. Проверить, что письмо приходит

1. Вверху редактора, справа от кнопок **Выполнить** и **Отладка**, есть список функций. Нажмите на него и выберите **testZayavka**, затем нажмите **Выполнить**.

   > Если в списке осталась `doPost` и вы нажали «Выполнить», появится красная ошибка `Cannot read properties of undefined (reading 'postData')`. Это нормально: `doPost` запускает сайт, когда приходит заявка, а вручную её выполнять нечем. Просто выберите в списке **testZayavka**.
2. Google спросит разрешение:
   - **Просмотреть разрешения** → выберите свой аккаунт;
   - появится экран «Google не подтвердил это приложение» → **Дополнительные настройки** → **Перейти к проекту (небезопасно)**. Это ваш собственный скрипт, так и должно быть;
   - **Разрешить**.
3. Через несколько секунд:
   - в таблице появится строка «Тестовая заявка»;
   - на почту придёт письмо «BAYERN — заявка: Тестовая заявка». Если письма нет — посмотрите в «Спам» и «Промоакции».

## Шаг 4. Опубликовать скрипт (получить ссылку)

1. В редакторе справа сверху нажмите синюю кнопку **Начать развёртывание** → **Новое развёртывание**.
2. Слева от слова «Выбор типа» нажмите на шестерёнку и выберите **Веб-приложение**.
3. Заполните:
   - **Описание**: `Форма сайта`;
   - **Запуск от имени**: **Я** (ваш адрес);
   - **У кого есть доступ**: **Все** ← это обязательно, иначе сайт не сможет отправлять заявки.
4. Нажмите **Развернуть**, при запросе — **Разрешить доступ**.
5. Скопируйте **URL веб-приложения**. Он длинный и выглядит так:
   `https://script.google.com/macros/s/AKfycb.........../exec`

Ссылку никому не показывайте: по ней можно отправлять заявки. Данные из таблицы по ней прочитать нельзя.

## Шаг 5. Вставить ссылку в сайт

1. Откройте файл [assets/js/main.js](assets/js/main.js).
2. В самом начале (примерно 27-я строка) найдите:
   ```js
   var FORM_URL = '';
   ```
3. Вставьте ссылку внутрь кавычек:
   ```js
   var FORM_URL = 'https://script.google.com/macros/s/AKfycb.........../exec';
   ```
4. Сохраните файл.

Либо просто пришлите мне ссылку — вставлю сам.

## Шаг 6. Проверить на сайте

1. Откройте сайт, заполните форму в разделе «Контакты» и отправьте.
2. Должно быть: на сайте появился зелёный экран «Спасибо», в таблице новая строка, на почте письмо.
3. Если форма написала красным «Не удалось отправить заявку» — смотрите «Если что-то не работает» ниже.

## Шаг 7. Выложить на сайт

Скажите мне — отправлю изменения на GitHub, и через пару минут форма заработает на живом сайте.

## Если что-то не работает

| Что видно | Что делать |
|---|---|
| Красная надпись «Не удалось отправить заявку» | Проверьте, что в шаге 4 в пункте «У кого есть доступ» стоит **Все**, и что ссылка в `FORM_URL` заканчивается на `/exec` (а не на `/dev`) |
| Письма нет, а строка в таблице есть | Посмотрите папки «Спам» и «Промоакции». Gmail шлёт не больше 100 писем в сутки — для заявок этого хватает с запасом |
| Заявка не приходит после того, как я поменял скрипт | После любой правки скрипта нужно нажать **Начать развёртывание** → **Управление развёртываниями** → карандаш → **Версия: Новая версия** → **Развернуть**. Ссылка при этом не меняется |
| Ошибка `Cannot read properties of undefined (reading 'postData')` | В списке функций выбрана `doPost`. Выберите **testZayavka** |
| Хочу проверить, жив ли скрипт | Откройте ссылку `/exec` в браузере. Должно показать `{"ok":true,"hint":"BAYERN form endpoint"}` |

## Как потом поменять адрес почты

Сайт трогать не нужно, ссылка `/exec` останется прежней.

1. Таблица → **Расширения** → **Apps Script**.
2. В начале кода поменяйте адрес в кавычках:
   ```js
   const NOTIFY_EMAIL = 'info@bayern.am';                        // один адрес
   const NOTIFY_EMAIL = 'info@bayern.am, levon.adamyan23@gmail.com'; // несколько — через запятую
   ```
3. Сохраните (**Ctrl + S**) и обязательно переопубликуйте: **Начать развёртывание** → **Управление развёртываниями** → карандаш → **Версия: Новая версия** → **Развернуть**. Без этого сайт продолжит работать со старой версией.
4. Проверьте: функция **testZayavka** → **Выполнить**.

> Отправителем писем всё равно остаётся аккаунт, в котором создан скрипт. Чтобы письма уходили с ящика компании, скрипт нужно создать заново уже под этим ящиком — тогда появится новая ссылка `/exec`, и её нужно будет вставить в `FORM_URL`.

## Полезное

- **Уведомление на телефон.** В Таблице: **Инструменты** → **Настройки уведомлений** → «Уведомлять, когда... изменения внесены» → «Сразу».
- **Спам-боты.** В форме есть невидимое поле-ловушка: если его заполнили, заявка отбрасывается.
- **Данные людей.** В таблице лежат имена и телефоны клиентов. Не открывайте к ней доступ «всем, у кого есть ссылка».
