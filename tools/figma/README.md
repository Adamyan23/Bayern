# Фото сайта: шаблоны Figma → сайт

Шаблоны для всех секций с фотографиями — в `tools/figma/templates/`:

| Файл | Секция | Что на сайте |
|---|---|---|
| `1-hero.svg` | Hero — фон за белым логотипом | слот `hero` (2400×1350) → `photos/hero/hero.jpg` |
| `2-about.svg` | О компании — коллаж | слоты `about-1` … `about-3` → `photos/about/about-N.jpg` |
| `3-industries.svg` | Отрасли — 4 галереи | фрейм `industries-0N` целиком → `photos/industries/0N.webp` |
| `4-brands.svg` | Бренды — коллажи 9 карточек | фрейм `brand-<id>` целиком → `photos/brands/<id>.webp` |

Карусель «Портфель» делается отдельно, в файле **BAYERN — Portfolio cards template** (см. [tools/cards/README.md](../cards/README.md)).

## 1. Открыть в Figma
Перетащите SVG-файлы на холст Figma (или **File → Import**). Серые прямоугольники — слоты, светлая подложка под ними — фрейм (`frame …`).

- Размер = размер готового фото (в 2 раза больше блока на экране 1440 px).
- Медный пунктир в Hero — где логотип, заголовок, что видно на ноутбуке и на телефоне.
- **Отрасли и бренды:** раскладка свободная — фото можно ставить как угодно в пределах подложки фрейма, в том числе одну картинку на несколько слотов. На сайт уходит весь фрейм одной картинкой.
- **Hero и О компании:** фото ставится в заливку слота (Fill → Image), имя слота не менять.

## 2. Экспорт
**Перед экспортом скройте слои `tag …`, `label …`, `hint …` и `guide …`** (подписи и пунктир).

### Отрасли и бренды — вся доска одним PNG
1. Выделите всю доску (слой `background`), **Export → PNG, 1x**.
2. Сохраните в `media/` (например `media/4-brands 1.png`).
3. Запустите (нужны `python -m http.server 5500` из корня проекта и Google Chrome):
   ```bash
   node tools/figma/crop.mjs "media/4-brands 1.png" tools/figma/templates/4-brands.svg
   node tools/figma/crop.mjs "media/3-industries 1.png" tools/figma/templates/3-industries.svg
   ```
   Скрипт вырезает каждый фрейм по координатам шаблона и сохраняет WebP в `assets/img/photos/…`:
   - плитки обрезаются точно по слотам, промежутки между ними прозрачные — на сайте у каждой плитки своя тень;
   - промежуток остаётся, если через него проходит фото с техникой (одна картинка на несколько слотов);
   - полосы холста у края фрейма заполняются продолжением фото, обрезки тоньше 24 px убираются;
   - верхний правый угол срезан (фирменный приём).

   Если подписи слотов забыли скрыть, он их сотрёт (цвет `#26373F`) и перечислит, где стёр — проверьте эти места глазами.

   Важно: доску не сдвигать и не менять её размер — координаты берутся из SVG.

   Если в Figma фото вышло за край фрейма (в экспорте оно обрежется), плитку можно собрать вручную из исходника в `media/` — [tools/figma/overrides.cjs](overrides.cjs). Так сделана правая колонка отрасли 02.

### Hero и О компании — тоже можно всей доской
```bash
node tools/figma/crop.mjs "media/2-about 1.png" tools/figma/templates/2-about.svg
```
Каждый слот сохраняется отдельным JPG (`photos/about/about-N.jpg`, `photos/hero/hero.jpg`), серые края (если фото не дотянули до края слота) обрезаются.
Для Hero надёжнее положить исходное фото без логотипа: если логотип (или любой слой поверх фото) попал в экспорт, он окажется на фоне дважды.

### Hero и О компании — отдельные слоты
1. Выделите заполненные слоты → **Export → JPG, 1x**, суффикс пустой → сохраните в `media/figma-export/`.
2. Запустите:
   ```bash
   node tools/figma/place.cjs
   ```

Сайт подхватывает фото сам — обновите страницу с **Ctrl + F5**. Пока файла нет, на сайте видны плитки-заглушки.

## Пересобрать шаблоны
Если поменялись раскладки коллажей (`tools/cards/brands.cjs` → `LAYOUTS`) или размеры блоков:
```bash
node tools/figma/templates.cjs
```
После этого старые PNG-экспорты для `crop.mjs` не подходят — доску нужно выгрузить заново.
