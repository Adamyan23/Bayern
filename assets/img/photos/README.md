# Фотографии для сайта BAYERN

Фото подставляются **автоматически**: положите файл с нужным именем в нужную папку — и он появится на сайте вместо заглушки. Код менять не нужно. Пока файла нет, на его месте остаётся цветная заглушка с подписью «Фото».

**Удобнее всего — через шаблоны Figma** ([tools/figma/README.md](../../../tools/figma/README.md)): там все слоты с точными размерами, а скрипт сам разложит файлы по папкам.

Общие правила:

- Формат — **`.jpg`**, имена — строго как в таблицах ниже (маленькими буквами, без пробелов).
- Цвет — sRGB, качество 75–85%. Размер одного файла — желательно **до 400–500 КБ** (сжать можно на [squoosh.app](https://squoosh.app)).
- Стиль по брендбуку: дневной свет, реальные объекты, техника в работе, люди в СИЗ и фирменной одежде. Без стоковых «строителей с планшетом», без логотипов конкурентов, без тяжёлых фильтров и HDR.
- Фото обрезаются по размеру блока (`cover`), поэтому главное держите ближе к центру кадра.

## Проверка

1. Положите файлы в папки.
2. Обновите страницу с очисткой кэша: **Ctrl + F5**.
3. Если фото не появилось — проверьте имя файла (регистр, `.jpg`, а не `.jpeg` или `.JPG`) и папку.

Где это настроено в коде: функция `loadPhoto` в `assets/js/main.js` и атрибуты `data-photo` в `index.html`.
